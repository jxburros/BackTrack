# BackTrack 0.7.0

## Changes

### Added

- **BackTrack Explode, milestone S0.** The stem separator runs end to end: `backtrack-explode`
  on the command line, a server on port 8827 that Song Deck's separation adapter uses as is
  (`POST /separate`, `GET /info` with `stems` and `on_request_stems`), and its page in the
  blast-zone theme. Stems are 44.1 kHz stereo and always sum back to the song. The model is a
  placeholder without training, so the stems are rough; the first trained model is S2.
  Explode is not packaged in this release's downloads yet (S3).
- `core/`: a short-time Fourier transform with an exact inverse.

Surveil and its models are unchanged from 0.6.1.
