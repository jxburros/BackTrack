# BackTrack 0.6.0

## Changes

### Added

- **Bass and melody models** for Surveil (`surveil-bass-0.1.0.gguf`, `surveil-melody-0.1.0.gguf`),
  attached to the release and shipped in the desktop apps. On 60 unseen songs per part rendered by
  Song Deck, against Song Deck's built-in transcription of the separated stems: bass note F 0.472
  against 0.211; melody 0.917 against 0.757 on instrumental leads and 0.684 against 0.372 on Song
  Deck's guide singer. Put them in a `models` folder next to `backtrack-surveil` and bass, melody
  and vocal stems use them.

### Changed

- **Drums 0.2.0** (`surveil-drums-0.2.0.gguf`) replaces drums 0.1.0: also trained on ACE-Step
  performances, F 0.848 against 0.837 for 0.1.0 and 0.527 for Song Deck's built-in transcription.
- ggml moves to `f1aa6a3` (0.27.0), Onyx Engine's revision. Notes are the same within the parity
  check's tolerance.

None of the scores includes real recordings yet; see `weights/README.md` in the repository.
